ABOUT SITESCOUT

A visual index of deployed websites.

SiteScout collects publicly discoverable URLs from supported hosting domains and turns them into a fast, screenshot-first directory.

Sources

Discovery adapters can use urlscan.io, Common Crawl and GitHub public search. Each source is isolated so another public source can be added without changing the frontend.

What we fetch

For a candidate site, SiteScout performs at most one polite homepage fetch during a collection pass, follows only safe HTTPS redirects within the supported hosting set, and checks a simple robots.txt policy first.

Scoring

The score is a technical signal based on HTTP response, timing, metadata, mobile viewport, HTTPS and security headers, plus a penalty for common default-template text.

No accounts

There are no accounts, comments, ratings or user profiles. The project is designed to work without a database. Feeds are generated and edge-cached for short periods.
