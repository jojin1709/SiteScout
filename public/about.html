How SiteScout Operates

A high-speed, database-less visual directory designed to index, audit, and showcase modern web applications deployed across free and edge cloud platforms.

🛰️

Multi-Source Discovery

SiteScout uses pluggable adapters connecting to urlscan.io, Common Crawl, and GitHub public search to find freshly deployed URLs with zero central database requirement.

🛡️

Safe & Polite Crawling

Every candidate URL is verified against robots.txt, respects strict timeout boundaries (7000ms), and only inspects public root landing pages on approved hosting domains.

📊

Automated 100pt Scoring

Our heuristic analysis scores each site based on HTTPS security, load latency, OpenGraph tags, mobile viewport responsiveness, and Content-Security-Policy headers.

⚡

Serverless & Edge Ready

Deployable anywhere from Vercel Serverless Functions to Cloudflare Pages and Workers. All discovery feeds are edge-cacheable for lightning fast 5-minute CDN delivery.
